PPSI / Manufacturing

Catching manufacturing-data mismatches earlier

Developed a Python comparison approach for checking manufacturing BOM data against pick-and-place information before a production run.

Context
PPSI
Period
2025
Project status
Script / prototype
Conceptual illustration

The engineering problem

Part numbers, quantities, and do-not-populate entries can drift between customer data, internal MRP records, and machine-preparation files.

My contribution

  • Worked with BOM conversion and validation for manufacturing preparation.
  • Built a CSV-oriented cross-checking script to compare BOM and placement data.
  • Structured discrepancy checks around part identifiers, population intent, and quantities.
  • Explored how a repeatable preflight check could reduce manual review.

Outcome & current scope

Developed a comparison script / prototype for reviewing manufacturing-data discrepancies before production. Production rollout was outside the documented scope.

What this taught me

Data normalization and a clear exception report are essential before automating an engineering check.
